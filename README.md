## 👋 Kısaca

<img align="right" src="https://derthert.com/assets/avatar-320.jpg" width="160" alt="Emirhan" />

İstanbul merkezli, bağımsız çalışan bir yazılım geliştiricisiyim. Ekiplerle ve şirketlerle; mimarisi baştan düşünülmüş, bakımı kolay ve büyümeye hazır sistemler kurmak üzerine çalışıyorum.

Bir işe başlamadan önce problemi doğru anlamaya zaman ayırırım. Hızlı ama kırılgan çözümler yerine, ihtiyaç değiştiğinde de ayakta kalabilen yapıları tercih ederim.

<sub>Geliştirdiğim işlerin çoğu müşterilere özel ve kapalı kaynak; burada görünenler resmin tamamı değil.</sub>

**Emirhan (`derthert`): Software Developer · Systems Architect**

I'm an independent software developer based in Istanbul. I work with teams and companies to design and build software from the first idea to production, with a focus on systems that are well-architected, easy to maintain and ready to scale.

Before writing any code, I take the time to understand the problem properly. I'd rather build something that holds up when requirements change than ship a quick but fragile fix. Most of my work is client-specific and closed-source, so what you see here is only part of the picture.

**Where I add value**

- **Backend & Infrastructure**: service architecture, API design, data modeling, Linux servers and deployment
- **Web Applications**: admin panels, customer portals, authentication and third-party integrations
- **Game Server Systems**: scalable infrastructure and performance-focused development for the Minecraft ecosystem
- **Desktop Software**: cross-platform applications for Windows, macOS and Linux
- **Automation**: tools and bots that streamline workflows, support and community operations
- **Technical Consulting**: architecture decisions, system reviews and restructuring plans

**How I work:** discovery & planning · iterative development · maintainable code · delivery & support
